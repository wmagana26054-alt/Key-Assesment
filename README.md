#Key-Assesment
Belize School Event Registration System

A menu-driven C++ console application designed for Belizean secondary school coordinators and student council officers to manage student sign-ups, check-ins, and room capacity for school workshops and events.

Features
- Register students with duplicate email prevention and fixed seat capacity (`MAX_STUDENTS = 30`)
- View all registered students and their check-in status
- Search for a student by full name
- Check in arriving students on event day
- Cancel registrations and automatically shift remaining records
- View live attendance summary (Total Registered, Checked In, Seats Available)

Requirments
- Visual Studio Code
